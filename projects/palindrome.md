# Overview
UHM Study is a web application for students to find study buddies online. It allows users to connect and schedule study sessions. The goal of this project is to solve students’ issues with not having someone to study with. This project aims to increase student productivity and network.

# Contributions
In this program, I was responsible for connecting data to the database, ensuring it was accurately routed and displayed in the appropriate locations. Additionally, I worked on styling several pages, including the Edit Profile page and the Create Sessions page, to enhance their visual appeal and user experience.

# Developement
This project provided valuable insights into the dynamics of effective teamwork in development. I learned the importance of clear communication to ensure that everyone stays aligned and informed throughout the process. Additionally, this project enhanced my proficiency with GitHub in a team setting, particularly through using features like push/pull upstream, creating pull requests, and working with forked repositories to make edits collaboratively.
