# Becoming a StudyBuddy
For my group's ICS 314 project, we were tasked with developing a website where students can plan study sessions and connect with classmates. The goal was to create a useful tool to supplement students' studies. Throughout the project’s development, I gained both soft and technical skills that significantly improved my coding abilities. Some of these skills include effective communication, efficient use of GitHub, and a deeper understanding of coding functions that I can now confidently replicate. 

The skills I developed during this project have exponentially enhanced the way I understand and write code. One key takeaway was learning to resolve errors by carefully analyzing error messages rather than immediately relying on AI tools. This approach helped me identify patterns in how programs work. For example, I noticed that all our database code followed a similar structure. Each database relied on a schema, and data was pulled using commands like student.id, student.name, and student.age. Here, the schema student served as a template, while the .something specified the data routed to particular databases and pages. Similarly, I recognized that most pages were constructed with consistent structures—it all boiled down to how we utilized the tools at our disposal.

This project also opened my eyes to the value of project-based learning. Over the course of a month, I gained as much, if not more, practical knowledge than in some ICS courses I’ve taken. Classroom lessons often focus on essentials for passing, leaving out practical nuances. For example, while the course recommended using GitHub Desktop for its user-friendly interface, I discovered that mastering bash commands offered me a more robust and efficient workflow. Using commands like git pull and git push, I could confidently manage version control, ensuring everything was in order before merging changes.

In conclusion, working on the StudyBuddy project has been an incredibly enriching experience. Beyond improving my technical skills, it taught me the importance of adaptability and collaboration in software development. By facing challenges head-on, learning from errors, and embracing efficient workflows, I’ve grown into a more capable and confident programmer. This project reaffirmed my belief that hands-on learning is one of the most powerful ways to develop skills and solidify knowledge in computer science.
